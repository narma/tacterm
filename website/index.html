GET YOUR HANDS ON IT

Start with
the source.

Public tacterm packages are still in preparation. You can build a development version with Rust {{RUST_VERSION}} or later and the platform dependencies.

The executable is currently called rio / rio.exe and uses Rio's configuration paths.

Build instructions ↗
FROM YOUR TERMINAL
git clone https://github.com/narma/tacterm.git
cd tacterm
cargo build --locked -p rioterm

Builds into target/debug/. Does not install.
