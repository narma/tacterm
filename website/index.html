Will it use my existing Rio settings?

Version 0.1.0 and current source builds use a separate tacterm directory and import Rio settings once when that directory is absent. The earlier 0.1.0-alpha.1 preview used Rio’s configuration paths. Later changes stay independent; see the status page for migration details.

How much of it has been tested?

Published archives pass native build, packaging, and command-line checks on all six OS and architecture targets. Those checks do not establish graphical stability on every display or GPU. See validation results and remaining limits before relying on a preview for critical work.

Does lower GPU memory use mean a faster terminal?

It means less memory reserved for glyphs at startup. Storage grows with the characters you use and can reach the original maximum. Throughput and latency are separate measurements; we do not claim a universal speedup.

Where can I get help or report a problem?

Use the Rio documentation for general configuration. For a tacterm issue, open a report on GitHub with your version, OS, GPU, and steps to reproduce it. Remove secrets from logs and configuration before sharing.

FOR DEVELOPERS

Build it.
Make it yours.

To try the development branch or contribute a fix, build from source with Rust {{RUST_VERSION}} or later and the dependencies for your platform.

Source builds and downloaded releases use tacterm / tacterm.exe. Current source builds keep their settings in a separate tacterm directory and import Rio settings on first launch.

Build instructions ↗
FROM YOUR TERMINAL
git clone https://github.com/narma/tacterm.git
cd tacterm
cargo build --locked -p rioterm

Builds into target/debug/. Does not install.
